# TopoPPI tools

[OptCuts](OptCuts/residue_aware/README.md) contains the native solver build scripts and residue-aware objective. [Affinity tools](../plugins/affinity/tools/README.md) provide reusable feature preparation, fitting and evaluation commands for user-supplied inputs.

Routine mapping uses the [application, CLI or Python API](../README.md). The [hotspot plugin](../plugins/hotspot/README.md) exposes residue ranking separately.
